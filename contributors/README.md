# Contributors

Everyone who finished module 00 has a file here.

To add yours, create `contributors/your-github-username.md` containing:

```markdown
# Your Name

- GitHub: [@your-github-username](https://github.com/your-github-username)
- Domain: AI/ML, Web Dev, or Cybersecurity
- One thing I want to build: [anything]
```

One file per person means nobody's pull request conflicts with anyone else's.
