# GDGoC NUST × Capital Youth Expo 2026

Submissions for the NUST round of the Capital Youth Expo AI Challenge and Innovation Sprint Hackathon.

## AI Challenge (Nov 25, 5:00–6:00 PM)
1. Download your notebook: Kaggle → File → Download notebook, or Colab → File → Download → .ipynb.
2. Open `events/cye-2026/ai-challenge/` → **Add file → Upload files**.
3. Before dropping files, type a folder name in the path box: `your-team-name/` (lowercase, dashes).
4. Upload your `.ipynb` and a `README.md` copied from `ai-challenge/TEMPLATE.md`.
5. **Propose changes → Create pull request.**

## Hackathon (by Nov 28, 11:59 PM)
1. Open `events/cye-2026/hackathon/` → **Add file → Create new file**.
2. Name it `your-team-name.md` and paste `hackathon/TEMPLATE.md`, filled in.
3. **Propose changes → Create pull request.**
