## Approach

We used a tabular classification approach with Random Forest and Extra Trees classifiers to identify solar-panel faults using sensor measurements. We experimented with both raw sensor features and engineered features, including electrical power, ratios, and squared values. We evaluated eight model and feature combinations using 5-fold Stratified Cross-Validation and selected the best configuration based on the Macro F1-score. Finally, we retrained the best-performing model on the complete training dataset to generate predictions for the test dataset.

## Features we made

- **Total Power (`dc_voltage × dc_current`):** Captures the electrical power generated by the solar panel.
- **Current per Irradiance (`dc_current / irradiance`):** Captures the relationship between current output and incoming solar radiation.
- **Voltage per Temperature (`dc_voltage / panel_temp`):** Helps identify voltage variations associated with panel temperature.
- **Power per Irradiance (`total_power / irradiance`):** Represents power output relative to available solar radiation.
- **Current Squared (`dc_current²`):** Introduces nonlinear information from current measurements.
- **Voltage Squared (`dc_voltage²`):** Introduces nonlinear information from voltage measurements.
- **Sensor Value Rounding:** Sensor readings are rounded to four decimal places to maintain consistent precision.
- **Missing Value Handling:** Median imputation handles missing and invalid feature values before model training.
